# Product Context: Developer Career Portfolio

## Register
brand

## Product Purpose
Membangun web portofolio personal kelas dunia untuk melamar pekerjaan (Software Engineer / Full Stack Developer / Frontend Engineer). Web dirancang untuk memberikan impresi profesional instan, memvalidasi kapabilitas teknis secara nyata melalui live project showcase, dan mempermudah recruiter / hiring manager mengontak kandidat atau mengunduh CV.

## Target Audience & Physical Scene
- **Hiring Manager & Tech Leads:** Meninjau portofolio di laptop/desktop workstation, mencari kandidat dengan standar arsitektur bersih, perhatian pada detail UI/UX, dan penyelesaian masalah riil.
- **Tech Recruiters & HR:** Membuka link dari CV/LinkedIn dalam beberapa detik, mencari ringkasan keahlian utama, tombol unduh CV yang jelas, dan link kontak langsung.

## Brand Voice & Aesthetic Lane
- **Aesthetic Lane:** Precision Modern Engineering (terinspirasi dari standar craft tinggi seperti Linear, Vercel, Raycast, & Stripe Developer Docs).
- **Tone:** Confident, sharp, highly organized, polished, technical excellence without fluff.
- **Voice Words:** Crisp, purposeful, tactile, high-signal.

## Anti-References (What We Reject)
- Template AI generic (kartu seragam dengan icon bulat besar, gradient text murahan, border tebal samping warna-warni).
- Hero section klise yang lambat atau membingungkan.
- Dummy placeholder teks/proyek tanpa makna nyata.
- Desain yang berat tanpa optimasi performa.

## Strategic Principles
1. **High Signal-to-Noise:** Informasi krusial (Skill, Best Projects, Experience, Contact, Resume) dapat diakses dalam hitungan detik.
2. **Modular Data Structure:** Seluruh data portofolio (biodata, riwayat kerja, proyek, sertifikat, skill) terpusat di satu file konfigurasi data agar user mudah memperbarui profil mereka.
3. **GitHub Pages Native:** Dirancang 100% static compatible tanpa backend runtime, didukung GitHub Actions build workflow otomatis.
4. **Delightful Craft:** Micro-interactions yang presisi, fluid typography, dark/light theme adaptif, dan responsivitas sempurna di semua resolusi.
